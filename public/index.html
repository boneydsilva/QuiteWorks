The first tool

WorkQueue — hand out work, and know how long it took.

A manager assigns tasks from a browser. Every employee sees their own queue in a thin strip at the top of their screen — not an app they have to remember to open. The clock starts by itself, and stops when they press Complete.

Getting started

Three double-clicks and you are running.

There is no account to create, no card to enter and no cloud region to choose. Everything installs from a folder you can carry on a USB stick.

Install the server

Run one file on the PC that stays switched on — the manager's machine is usually the right one. It starts itself at boot from then on, and prints the web address for the dashboard.

Install the strip

Run one file on each employee PC. It finds the server on the network by itself, so there is no address to type and no admin password to chase.

Name the machines

Open the dashboard, type each person's name next to their PC, and start assigning. That name is what appears on their strip and in every report.

Questions

The things people ask first

Do we need a server, or IT people?

Neither. The "server" is a program that runs on an ordinary Windows PC you already have — usually the manager's. If someone in the office can install a printer, they can install this. If you would rather not, we will do it for you over a remote session.

What happens when the Wi-Fi goes down?

Employees keep seeing their tasks and keep marking them complete. Those actions queue up on their own PC with the real time they were clicked, and are delivered when the network comes back — so a task finished at 10:35 during an outage is still recorded as 10:35.

Can people use it from home, or from another branch?

Yes. WorkQueue can be joined to a private network (Tailscale) so laptops outside the office reach the same server securely, with nothing exposed to the public internet. It is one extra step during setup, and it is included.

Is this only for Windows?

Today, yes — both the dashboard PC and the employee PCs need Windows 10 or 11. The dashboard itself is just a web page, so it opens on any device on your network, including a phone. Mac and Linux employee support is on the roadmap rather than in the box, and we would rather say so plainly.

What do we get for the money, exactly?

A licence for your whole company — every PC in the office, no per-seat counting — a year of updates, and email support. Full details are on the pricing page.
